This repository contains code for the paper:

"Entropy of Soft Random Geometric Graphs in General Geometries"

O Baker, CP Dettmann - arXiv preprint arXiv:2601.15194, 2026

It contains the following code and data.

1) Jupyter notebooks
     - Contain numerical verification of Theorems 1, 2 3 and 4 in the paper.
     - Only require common python packages (numpy, matplotlib, scipy) as well as scienceplots for figure graphics. If unable to install scienceplots, it can be disabled by removing it from the import statment, and removing the line 'plt.style.use(['science', 'ieee', 'no-latex'])'.

2) C++ scripts
     - Plot every figure except Figures 1 and 2.
     - The figures are plotted in the notebook 'plotting.ipynb', but the data is generated by the c++ scripts in the 'scripts' directory. All output data may be found in the 'data' directory.
     - Syntax:
         - ./annulus_curves <number of points> <path loss exponent> <number of iterations> <r0 min> <r0 max> <r0 step> <minor radius>
         - ./annulus_mass <path loss exponent> <number of iterations> <connection range r0> <step_r> <step_theta> <minor radius>
         - ./cantor <number of points> <path loss exponent> <number of iterations> <r0 min> <r0 max> <r0 step> <cantor ratio> <cantor recursion depth>
         - ./square_curves <number of points> <path loss exponent> <number of iterations> <r0 min> <r0 max> <r0 step>
         - ./square_mass <path loss exponent> <number of iterations> <connection radius r0> <r0 step>
         - ./wedge_curves <number of points> <path loss exponent> <number of iterations> <r0 min> <r0 max> <r0 step> <max wedge angle>
         - ./wedge_mass <eta> <L> <r0> <step_r> <step_theta> <max_angle>
     - NOTE: these scripts make use of parallelisation through OpenMP. To compile, use ./script_name.cpp -fopenmp -o output_name.
